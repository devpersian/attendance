# 🗄️ راهنمای راه‌اندازی دیتابیس تمیز

## 📋 معرفی

دو اسکریپت SQL برای راه‌اندازی دیتابیس ارائه شده است:

1. **`clean-db.sql`** - ایجاد دیتابیس تمیز با فقط داده‌های اولیه ضروری
2. **`schema.sql`** - اسکریپت کامل با داده‌های نمونه

---

## 🎯 کدام اسکریپت را استفاده کنم؟

### استفاده از `clean-db.sql` (توصیه می‌شود)
✅ **کی استفاده کنیم:**
- می‌خواهید یک شروع تازه داشته باشید
- نمی‌خواهید داده‌های نمونه در دیتابیس باشد
- می‌خواهید خودتان کارکنان و داده‌ها را اضافه کنید
- محیط production یا staging

✅ **مزایا:**
- دیتابیس تمیز و سبک
- بدون داده‌های اضافی
- کنترل کامل روی داده‌ها
- **سریع‌تر از DROP/CREATE** (فقط TRUNCATE می‌کند)
- **ساختار دیتابیس حفظ می‌شود** (نیازی به ایجاد مجدد جداول نیست)

✅ **روش کار:**
- تمام جداول را TRUNCATE می‌کند (پاک کردن سریع داده‌ها)
- ساختار جداول و ایندکس‌ها دست نخورده باقی می‌ماند
- فقط داده‌های اولیه ضروری را insert می‌کند

### استفاده از `schema.sql`
✅ **کی استفاده کنیم:**
- می‌خواهید سریع تست کنید
- نیاز به داده‌های نمونه دارید
- محیط development
- اولین بار دیتابیس را ایجاد می‌کنید

✅ **مزایا:**
- داده‌های نمونه از پیش پر شده
- آماده برای تست سریع
- شامل CREATE DATABASE و CREATE TABLE

## 🚀 مراحل راه‌اندازی

### روش 1: دیتابیس تمیز (توصیه می‌شود)

#### مرحله 1: اجرای clean-db.sql
```bash
# با SQLCMD
sqlcmd -S localhost -U sa -P YourPassword123! -i database/clean-db.sql

# یا با SQL Server Management Studio
# 1. فایل clean-db.sql را باز کنید
# 2. Execute (F5)
```

**خروجی مورد انتظار:**
```
========================================
Database cleaned and initialized!
========================================

All tables truncated and initial data inserted:
- 1 Company Info
- 1 Admin User (username: admin)
- 3 System Roles
- 25 Permissions
- 4 Default Shifts
- 1 Working Hours Rule (Friday)
- 2 Shift Patterns

Next steps:
1. Run seed-admin.mjs to set admin password
2. Start the server: npm run server
3. Login with admin/admin123
========================================
```

**نکته مهم:** این اسکریپت فقط داده‌ها را پاک می‌کند (TRUNCATE) و ساختار دیتابیس را حفظ می‌کند. اگر دیتابیس وجود ندارد، ابتدا باید `schema.sql` را اجرا کنید.

#### مرحله 2: تنظیم رمز عبور admin
```bash
npm run seed:admin
```

**خروجی مورد انتظار:**
```
🔐 Seeding admin user...
✅ Admin user created successfully!
   Username: admin
   Password: admin123
   ⚠️  Please change the password after first login!
```

#### مرحله 3: راه‌اندازی سرور
```bash
npm run server
```

#### مرحله 4: ورود به سیستم
- URL: http://localhost:3000/login
- Username: `admin`
- Password: `admin123`

## 🔄 پاک کردن کامل دیتابیس

اگر می‌خواهید دیتابیس را کاملاً پاک کنید و از اول شروع کنید:

### روش 1: استفاده از clean-db.sql (سریع‌تر)
```bash
sqlcmd -S localhost -U sa -P YourPassword123! -i database/clean-db.sql
```

این اسکریپت:
1. تمام جداول را TRUNCATE می‌کند (پاک کردن سریع داده‌ها)
2. ساختار جداول و ایندکس‌ها را حفظ می‌کند
3. فقط داده‌های اولیه ضروری را insert می‌کند

**مزایا:**
- ⚡ سریع‌تر از DROP/CREATE
- 🔒 ساختار دیتابیس حفظ می‌شود
- 🎯 فقط داده‌ها پاک می‌شوند

### روش 2: استفاده از SQL Server Management Studio
1. به SQL Server متصل شوید
2. روی دیتابیس AttendanceDB راست کلیک کنید
3. Tasks → Generate Scripts را انتخاب کنید
4. تمام جداول را انتخاب کنید
5. Script را اجرا کنید تا ساختار را ذخیره کنید
6. سپس فایل clean-db.sql را اجرا کنید

### روش 3: DROP و CREATE کامل (اگر ساختار را هم می‌خواهید تغییر دهید)
```bash
# ابتدا schema.sql را اجرا کنید (دیتابیس را drop و recreate می‌کند)
sqlcmd -S localhost -U sa -P YourPassword123! -i database/schema.sql

# سپس seed-admin.mjs را اجرا کنید
npm run seed:admin
```

## 🐛 عیب‌یابی

### مشکل 1: خطا در اجرای clean-db.sql

**علت:** دیتابیس در حال استفاده است

**راه حل:**
```sql
-- ابتدا تمام connection ها را ببندید
ALTER DATABASE AttendanceDB SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
DROP DATABASE AttendanceDB;
```

سپس clean-db.sql را اجرا کنید.

---

### مشکل 2: seed-admin.mjs خطا می‌دهد

**علت:** دیتابیس ایجاد نشده است

**راه حل:**
1. ابتدا clean-db.sql را اجرا کنید
2. سپس seed-admin.mjs را اجرا کنید

---

### مشکل 3: نمی‌توانم وارد سیستم شوم

**علت:** رمز عبور admin تنظیم نشده است

**راه حل:**
```bash
npm run seed:admin
```

---

## 💡 نکات مهم

### 1. ترتیب اجرا
همیشه این ترتیب را رعایت کنید:
1. `clean-db.sql` یا `schema.sql`
2. `npm run seed:admin`
3. `npm run server`

### 2. پشتیبان‌گیری
قبل از اجرای clean-db.sql، از دیتابیس فعلی بکاپ بگیرید:
```sql
BACKUP DATABASE AttendanceDB 
TO DISK = 'C:\Backup\AttendanceDB.bak';
```

### 3. محیط‌های مختلف
- **Development**: از `schema.sql` استفاده کنید (داده‌های نمونه)
- **Staging/Production**: از `clean-db.sql` استفاده کنید (دیتابیس تمیز)

### 4. رمز عبور admin
بعد از اولین ورود، حتماً رمز عبور admin را تغییر دهید:
1. وارد سیستم شوید
2. به تنظیمات پروفایل بروید
3. رمز عبور را تغییر دهید
