**کلاس‌های اصلی:**
```css

.btn-secondary - دکمه ثانویه (سفید)

.btn-success   - دکمه موفقیت (سبز)
.input         - فیلد ورودی
.badge-*       - نشان‌های معنایی
.section-title - عنوان بخش
.stat-number   - عدد آماری
.time-display  - نمایش زمان
```

### 4. انیمیشن‌ها

**ظریف و هدفمند:**
```css

scaleIn  - بزرگنمایی (150ms)
stagger  - تأخیر 40ms بین عناصر
```

## 🎯 اصول طراحی

### 1. سلسله‌مراتب بصری
- عناوین بزرگ و تیره
- متن بدنه با اندازه متوسط
- برچسب‌ها کوچک و خاکستری
- استفاده از وزن فونت برای تأکید

### 2. فضا
- padding سخاوتمندانه (24px)
- gap مناسب (16px)
- تنفس بصری کافی
- عدم شلوغی

### 3. رنگ
- یک رنگ تأکیدی (آبی)
- رنگ‌های معنایی برای حالت‌ها
- خاکستری‌های متعدد برای سلسله‌مراتب
- بدون رنگ‌های اضافی

### 4. تعامل
- hover states ظریف
- focus rings واضح اما نه آزاردهنده
- active states فوری
- transition‌های سریع (150-200ms)

### 5. تایپوگرافی
- اعداد قوی برای زمان و آمار
- فونت‌های خوانا
- فاصله‌گذاری مناسب بین خطوط
- tracking tight برای عناوین
